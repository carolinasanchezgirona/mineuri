Gestor editorial de perfiles

Editor local para preparar y revisar fichas del directorio. Funciona en este navegador y permite importar o exportar archivos JSON. No se conecta con la web publicada.

Importante: esto no es un panel de administración online. Nada de lo que modifiques se publica automáticamente. No guardes en esta herramienta documentos de identidad, datos de pacientes ni acreditaciones escaneadas. La verificación y la autorización de publicación deben comprobarse y documentarse mediante canales apropiados.

Gestión de fichas

Cada fila es una solicitud profesional. Puedes editar los campos, archivar, eliminar y preparar un JSON de publicación con las fichas autorizadas.

Vista preliminar

Muestra las fichas con estado «aprobado», verificación y autorización marcadas. La previsualización no cambia la web pública.

Procedimiento de publicación

Después de verificar documentalmente la habilitación aplicable, la colegiación y el consentimiento de publicación, exporta el archivo «perfiles publicables». Revisa los campos y prepara un cambio de contenido en GitHub. No hay sincronización automática hasta que exista un servicio independiente con autenticación y permisos.

Los archivos se descargan a tu ordenador. Este editor no almacena fichas entre visitas ni transmite información a servidores.
